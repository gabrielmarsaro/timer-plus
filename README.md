# Timer Plus

Timer de treino HIIT/Tabata para **Android, iPhone, tablet e navegador**.

## iPhone (Safari)

### https://hybrid-comet-5wn2wku.shipstatic.com/

1. Abra no **Safari**.  
2. **Compartilhar** → **Adicionar à Tela de Início**.  
3. Abra o ícone **Timer Plus**.

No treino, **EXERCÍCIO** e **DESCANSO** ocupam a tela sozinhos (modo foco).

## Android (APK)

**https://github.com/gabrielmarsaro/timer-plus/raw/main/releases/timer-plus-debug.apk**

## Desenvolvimento

```bash
npm install
npm run dev
npm run build:docs
npm run android:apk
npm run smoke
node scripts/smoke-focus.mjs
```
